My Home Lab

Project Conception

Building my first server was one of the most engaging projects I undertook because it provided a practical way to learn how to work with remote systems and Linux-based environments. The goal was to create a personal development platform where I could experiment freely, host websites, and run Minecraft servers whenever I wanted to step away from work. To do this, I chose a Dell R610 as the foundation of the project. After a two-and-a-half-hour drive to Chapin, I acquired the system and began the build.

Bringing this legacy hardware into a modern environment was a significant challenge. The platform was no longer officially supported, and drivers and software were scarce or unavailable through conventional channels. After extensive research, I found custom drivers developed by an anonymous IT professional, which enabled me to bring "JServer" online on my LAN and eventually expose it to the wider WAN.

Configuration and Environment

When configuring this server, I chose Ubuntu Server as the foundation of the environment. Linux has been one of the most empowering experiences I’ve had with computing, and a Unix-based server stack felt like the right fit given my appreciation for macOS and the strong support Ubuntu Server provides for older hardware.

For web hosting, I selected NGINX and Uvicorn. NGINX’s reverse proxy capabilities help secure the backend from potential attacks, while Uvicorn offers a lightweight, efficient framework for serving my APIs.

My Experience

Building this server into its current state was a defining experience that ultimately shaped my career direction. Working with a complex machine in a real-world environment gave me a deeper understanding of what it takes to maintain internet-facing systems. From exposing the server to the internet and configuring my first cron job to automate a script, to finally bringing a live website online, the process was an immersive journey through IT and full-stack development. It gave me practical experience in networking, systems administration, and software engineering.
